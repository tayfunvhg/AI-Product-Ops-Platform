# Контекст проекта (передача между сессиями)

Краткая «карта» для любого, кто продолжает работу над прототипом —
человека или Claude в новой сессии. Подробности по запуску — в `README.md`.

## Что это
Кликабельный прототип платформы **AI Product Ops** (X5) — продуктовое
управление с встроенными ИИ-агентами. Реализует целевое видение
(**Вариант B**: агенты глубоко встроены в продуктовый процесс; решение всегда
за человеком). Целевые метрики видения: Lead Time −60%, FTE Stretch 0,
Adoption 70%, Span of control 1→2+, Time-to-decision ×2.

## Стек
Next.js 14 (App Router) + TypeScript + Tailwind. Без БД — данные в
`src/lib/mock.ts`. Агенты работают через серверные роуты.

## Структура
- `src/app/*` — разделы: Главная, `vision`, `discovery`, `tactical`,
  `execution`, `monitoring`, `settings`.
- `src/app/api/agent/route.ts` — чат агента → LLM.
- `src/app/api/x5/health/route.ts` — проверка подключения к LLM.
- `src/components/AgentPanel.tsx` — панель агента (чат + вложение файлов 📎).
- `src/lib/x5.ts` — клиент LLM (X5/DeepSeek), выбор провайдера, robust-парсинг.
- `src/lib/agents.ts` — реестр агентов и их системные промпты.
- `src/prompts/metric-generator.md` — полный промпт агента «Генератор метрик».

## Состояние (что готово)
- Все разделы свёрстаны, засеяны демо-данными, кликаются.
- Рабочий агент **«Генератор метрик»** (Monitoring & Alert), заземлён на
  видение/OKR/метрики продукта. Остальные агенты — заготовки с промптами.
- Поддержка двух LLM-провайдеров (переключение через `.env.local`).
- Вложение текстовых материалов в чат агента (txt/md/csv/json/yaml).
- Сборка чистая (`npm run build`), 10 роутов.

## LLM: переключение провайдера
В `.env.local` (этот файл **в .gitignore**, ключи в git не попадают):
- `LLM_PROVIDER="x5"` — X5 Copilot (нужен доступ к сети X5 / VPN).
- `LLM_PROVIDER="deepseek"` — DeepSeek (публичный, для локального теста без VPN).
После изменения `.env.local` — **перезапустить dev-сервер** (он читает env при старте).
Проверка: Настройки → «Проверить подключение» (или GET `/api/x5/health`).

Заметка по X5: документный хост `api-copilot.x5.ru` резолвится только из сети
X5/VPN; в `x5.ts` есть авто-перебор хостов только при сетевых ошибках.

## Как запускать
- Десктоп Claude → вкладка Code → **Local** → папка `~/AI-Product-Ops-Platform`.
- Или вручную: `npm install && npm run dev` → http://localhost:3000
- Или `./start-mac.sh` (ставит Node при необходимости, поднимает сервер).
- Сервер не зависит от Claude: под VPN можно закрыть Claude и поднять сервер
  вручную для работы с X5.
