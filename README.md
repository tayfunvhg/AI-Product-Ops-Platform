# AI Product Ops — прототип платформы

Кликабельный прототип платформы продуктового управления с ИИ-агентами
(концепция AI Product Ops, X5). Реализует **Вариант B** из целевого видения:
платформа, в которую ИИ-агенты **глубоко встроены** в продуктовый процесс
(Discovery → Tactical → Execution), на слое **Data Driven & Metrics** и
**Monitoring & Alert**. Агенты предлагают артефакты — **решение всегда за человеком**.

> Это first-version прототип: данные моковые (засеяны), агенты — рабочий каркас
> поверх **X5 Copilot**. Интеграция с LLM готова и включается одним ключом.

## Стек

- **Next.js 14** (App Router) + **TypeScript** + **Tailwind CSS**
- Серверные API-роуты для агентов (`/api/agent`) и проверки LLM (`/api/x5/health`)
- Без базы данных — данные в `src/lib/mock.ts`

## Запуск локально

```bash
npm install
npm run dev
# открыть http://localhost:3000
```

Сборка прод-версии:

```bash
npm run build && npm start
```

## Подключение X5 Copilot

Агенты ходят в LLM через серверный роут (ключ **не** утекает в браузер).
Настройки берутся из переменных окружения — см. `.env.example`:

```bash
X5_COPILOT_API_KEY="..."
X5_COPILOT_COMPLETIONS_URL="https://api-copilot.x5.ru/aigw/v1/chat/completions"
X5_COPILOT_MODEL="copilot-flash"
X5_COPILOT_AUTH_MODE="bearer"   # или x-api-key
```

Для удобства в репозитории есть локальный `.env.local` (он **в .gitignore** и
не попадает в git) с уже вписанным ключом прототипа.

Проверить связь: раздел **Настройки → «Проверить подключение»** (вызывает
`/api/x5/health`). Эндпоинт `api-copilot.x5.ru` внутренний — он резолвится
только из сети X5 / по VPN. Если агент не отвечает, UI остаётся рабочим и
показывает понятное сообщение, а не падает.

## Разделы (по вашим скринам)

| Раздел | Что внутри | Агенты |
| --- | --- | --- |
| **Главная** | Мой ИЗИ (индекс здоровья инициатив), Динамика ИЗИ, бэклог | — |
| **Vision & Strategy** | Текущее видение, ставки, презентации | Агент обновления видения |
| **Discovery** | Персоны, список гипотез, бэклог, история брифов, дайджесты | Агент гипотез, Агент по персонам |
| **Tactical Planning** | Черновик OKR, роадмап Now/Next/Later | Агент тактического планирования |
| **Execution** | Поток исполнения, связь с инициативами | Агент исполнения |
| **Monitoring & Alert** | Продуктовые и производственные метрики + алерты | Цифровой агент по мониторингу |
| **Настройки** | Источники ввода/вывода, подключение LLM | — |

Сверху — переключатель **роли** (PO / CPO / APO / …) и аватар пользователя.

## Структура

```
src/
  app/
    layout.tsx              # каркас: сайдбар + топбар
    page.tsx                # Главная
    vision|discovery|...    # разделы
    settings/page.tsx       # Настройки + тест X5
    api/
      agent/route.ts        # чат агента -> X5 Copilot
      x5/health/route.ts    # проверка подключения к X5
  components/
    Sidebar / Topbar
    AgentPanel.tsx          # переиспользуемая панель агента (чат)
    X5ConnectionTest.tsx
    ui.tsx                  # PageHeader, Sparkline, Section, ...
  lib/
    x5.ts                   # клиент X5 Copilot (оба auth-режима, robust parsing)
    agents.ts               # реестр агентов + системные промпты
    mock.ts                 # засеянные данные
```

## Как развивать дальше

- **Промпты агентов** — `src/lib/agents.ts` (легко редактировать/добавлять).
- **Реальные действия агентов** (создание гипотезы, карточки в трекере) —
  сейчас агенты только предлагают текст; следующий шаг — строгий JSON-контракт
  на action'ы (хелперы `extractJson` уже есть в `src/lib/x5.ts`) с подтверждением
  человеком перед применением.
- **Данные** — заменить `mock.ts` на реальные источники (Confluence / Jira / API).
